# 林间斗兽棋 1.13 发布更新说明

版本名称：1.13。Android versionCode：16。Spatial SDK：6.2.8。

本次发布恢复并保留 Mixed Stage 与应用内天空沉浸度 UI。系统旋钮不控制此项设置。
「天空沉浸度」提供 0–100% 滑杆，以及全透、半沉浸、全沉浸快捷按钮。
仅天空实体与天空材质接受调节；棋盘、棋子、树木、地面装饰和胜利烟花不随设置改变。
首次默认 100%，本机保存选择。主页 640×608dp，设置页 640×368dp。

从线上 1.5 升级还包含森林与棋子视觉完善、胜利表现、八种真实动物叫声，以及独立的
背景音乐和棋子音效开关。录音来源和许可见「真实动物音频来源与许可.md」。

## 发布检查中的修正

- 音频焦点申请失败时清除已请求状态，允许后续音频开关操作重新申请。
- 拖拽坐标使用公开的 SpatialCoordinateSpace 转换到棋桌，移除受限 origin 接口调用。
- 天空设备测试统一在主线程读取 SDK 实体，主线程 helper 支持嵌套调用。
- 需要外部操作的退出测试仅在 `-e manual_exit true` 时启用，默认回归跳过。
  这项跳过不代表退出按钮已完成本轮验收。
- Git 和源码打包均排除私有配置、签名、环境配置和日志。
- 音频许可文件仅清理末尾空行，许可内容不变。

## Vibe Lab 更新文案

新增应用内天空沉浸度设置，支持全透、半沉浸、全沉浸及滑杆调节，并保存选择。
调节只影响天空，森林棋桌、动物棋子和交互持续保留。新增背景音乐与棋子音效独立开关，
八种棋子采用真实动物录音，完善森林细节、对局反馈与胜利表现。
修复音频焦点恢复问题，保留原生手势抓放、点选落子与 AI 对战。
