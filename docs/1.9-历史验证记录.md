# 林间斗兽棋 1.9 — 混合林与轻快背景音乐

日期：2026-11-24。`com.pico.junglechess`，versionName=1.9，versionCode=12。

## 周围树木

- 周围24棵树混合圆冠、尖顶针叶、细长树冠、舒展阔叶四种样式，每种6棵。
- 随机调整顺序、角度、林圈半径、高度和冠幅。使用固定随机种子19进行资源生成，
  每次打开应用保持同一布局；不是运行中持续随机刷新。
- 本批树木高度参数为1.681–3.610米，冠幅也存在差异。林圈距中心3.35–3.95米，
  棋桌及中央活动区域保持空旷，原有草花、石头、兔子和松鼠保留。
- 新forest.glb为24,256三角形、12,454顶点、641,252字节。
  仍为单mesh、不透明、顶点色烘焙柔光、KHR_materials_unlit，不增加树木碰撞或互动。
- `generate_mixed_forest.py`独立重建森林，避免重建棋盘、棋子及天空。
  `mixed_forest_manifest.json`记录各棵树样式、高度、宽度和位置。

## 背景音乐

原创曲《林间散步 / Woodland Stroll》，C大调、112BPM、4/4拍、32小节，
长度68.571秒。以轻木琴旋律、温暖拨弦和弦、柔和低音、轻沙锤及鼓点编配，
中段有较安静的笛音变化；无歌词，无第三方采样及外部曲目依赖。

音频为32kHz双声道16-bit PCM WAV，8,777,188字节。文件不压缩，
通过assets文件描述符由MediaPlayer异步准备及流式播放；不在游戏帧循环中合成音频。
离线制作时将尾音及短混响按周期折回开头，消除整段末尾的空白。
平均电平约−20dBFS、峰值约−5.17dBFS，未削波，首尾PCM采样差为0。

播放规则：

| 场景 | 音乐行为 |
|---|---|
| 棋局模型加载完成且Stage可见 | 自动申请音频焦点并循环播放 |
| 打开规则、设置或结果面板 | 同一播放器继续播放 |
| 新开一局 | 保持背景曲连续，不重复叠加播放器 |
| Stage进入后台 | 暂停并释放音频焦点 |
| 返回棋局 | 从暂停位置继续 |
| 临时失去音频焦点 | 暂停，重新获得焦点后继续 |
| 系统要求降低音量 | 降低背景曲音量 |
| 关闭Stage或结果弹窗退出游戏 | 释放播放器及音频焦点 |
| 音频加载失败或焦点未获准 | 棋局继续运行；不强行播放 |

播放器归属于Stage的AndroidViewModel，并有Composition销毁及ViewModel清理两层释放。
信息面板不创建播放器。普通播放音量系数0.35，降低音量时0.075，同时遵循系统媒体音量。
没有后台服务、网络请求或进程退出后继续播放的机制。
