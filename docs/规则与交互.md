# 规则调研与实现约定

调研日期：2026-11-11。棋盘采用用户已确认的7×9经典布局。
斗兽棋存在地方玩法，以下明确本应用选用的规则，避免把变体误称为唯一官方标准。

## 规则判定表

| 场景 | 判定 |
|---|---|
| 普通移动 | 横向或纵向一格，禁止斜走、越界和占据己方棋子 |
| 回合 | 红方先行，每回合一着；AI固定执蓝 |
| 普通吃子 | 等级大于或等于对方可吃，同级可互吃 |
| 鼠象 | 陆地鼠可吃象；象不可吃鼠 |
| 入水 | 仅鼠可进入河格 |
| 水中吃子 | 水鼠可吃相邻水鼠 |
| 跨水岸吃子 | 两个方向都禁止；出入空岸格正常移动 |
| 狮虎跳河 | 沿横/竖方向跳到对岸最近陆地格，不得中途停水中 |
| 跳河阻挡 | 路径河格有任意阵营的鼠则不可跳；路径外的鼠不影响 |
| 跳河吃子 | 落点为敌子时按等级判定；不可落在己子上 |
| 己方陷阱 | 自己进入不降低等级 |
| 敌方陷阱 | 棋子有效等级降至0，可被任何守方动物吃掉，包括象吃陷阱中的鼠 |
| 陷阱内主动吃子 | 被困棋子不能吃出陷阱；可以走到空格，离开后恢复原等级 |
| 兽穴 | 不可进入己方兽穴；任何己子进入对方兽穴立即获胜 |
| 清子 | 对方已无棋子，当前行棋方获胜 |
| 困毙 | 对方轮到走但无合法走法，当前行棋方获胜 |
| 重复和棋 | 棋子位置及轮到哪方相同，累计第三次出现判和 |
| 无进展和棋 | 连续100步（双方合计100着）无吃子判和；吃子后重置 |
| 判定优先级 | 入穴→清子→困毙→重复和棋→无进展和棋 |
| 终局 | 停止选子、拖动和AI；保留最终局面，自动显示结果弹窗；点击「新开一局」直接重新开始 |

## AI

两档均采用 negamax 形式的 minimax、alpha-beta 剪枝和走法排序，共用同一局势评分；不再随机选择合法走法。
简单难度搜索2层，覆盖AI走一步及玩家下一步应对；困难难度迭代加深至最多6层。
一层为任一方的一步，6层相当于最多3轮双方交替走子。困难按最后完整搜索轮次落子，不保证每次都达到6层。
两档先完成基础2层搜索，困难更深搜索受1100ms软时间预算限制；已找到确定获胜走法时提前结束，取消任务返回无决策。
搜索预算约1100ms，保留最后完整搜索层的最佳着；无法完成首层时仍返回合法备选。
评估包括子力、距离敌穴、临近兽穴威胁、陷阱风险、被吃风险、机动性和水鼠位置。

AI在后台协程执行，先延迟500ms让玩家走子动画完成。
切难度与重开会取消旧协程，并使用代次标识阻止过期结果落入新棋局。
预算检查有批次粒度，1100ms是目标预算而非硬实时保证。

## 空间交互

| 触发 | 行为与异常反馈 |
|---|---|
| 选中己子 | 显示金色圈、名称、等级、坐标及合法落点数量 |
| 抓起 | 棋子略抬起，使用原生3D拖拽增量转换到棋桌本地坐标，平滑跟随 |
| 移动 | 绿色圈提示合法落点；当前非法候选落点显示红色圈 |
| 松手 | 依棋桌本地位置取最近格；合法则吸附并进入AI回合 |
| 非法/盘外/过高松手 | 不修改棋局，动画返回原格，显示非法落点说明 |
| 取消手势 | 返回原位，清除选择，不产生回合 |
| 点选替代 | 点己子后点合法格或可吃敌子，复用相同规则引擎 |
| AI思考中 | 拒绝玩家选择和落子；难度、新对局控件可用 |
| 切换难度 | 保留棋局；若正值AI回合，以新难度重新计算 |
| 新对局 | 先显示确认；确认后重置棋盘并保留难度 |
| 终局结果 | 原生AlertDialog显示「你赢了！」「AI 获胜」或「本局和棋」及结束原因；面板关闭时自动恢复 |
| 新开一局 | 结果弹窗按钮直接重开，停止跳动与烟花，恢复初始棋子；保留难度和棋盘位置 |
| 胜方庆祝 | 最后落子结束后，胜方仍存活的每枚棋子在原格上方循环跳动，频率0.9–1.53Hz、高度4.5–12.2cm、相位不同 |
| 天空烟花 | 仅玩家获胜播放，天空左中右三组错峰升空、绽放、下落，9秒后停止；AI获胜及和棋不播放 |
| 关闭结果弹窗 | 使用系统关闭手势；保留最终棋局并继续胜方跳动；可通过主页「新对局」确认重开 |
| 棋桌调整 | 每次旋转45°、升降0.08m，高度范围0.55—1.10m；调整前取消拖拽 |
| 复位 | 棋桌中心恢复(0,0.74,-1.12)m，Y轴角度归零 |
| 面板拖拽 | 操作面板为原生WindowContainer，捏合系统拖拽栏调整空间位置；不改变棋盘 |
| 关闭面板 | 使用系统关闭控件；Stage及同一局棋仍保留，应用内不再显示收起按钮 |
| 打开操作面板 | 优先恢复最小化窗口，否则按固定id/tag打开；重复点击复用同一窗口 |
| 打开入口显隐 | 面板打开时移除入口按钮并禁用对应空间实体；收起/关闭后重新显示；不以窗口焦点或视线判断 |
| 退出场景 | Stage停止显示或销毁时同步关闭操作面板，包含规则页、设置页及结果弹窗；后台不允许延迟回调重新打开面板 |
| 再次进入场景 | 场景可见且资源就绪后恢复一个操作面板，避免重复创建 |
| 棋盘设置 | 主页难度下方进入独立页面；上升/下降、左转/右转、中心复位构成十字布局 |
| 设置页关闭 | 「关闭」按钮或系统返回键回到主页，保持同一棋局和难度 |
| 查看规则 | 原生Sheet；关闭后返回同一棋局 |
| 资源加载异常 | 面板显示重开提示，日志保留原因，释放已加载资源 |

棋子释放需靠近桌面：落点高度接受范围为棋桌局部Y=-0.06—0.42m。
3D棋桌世界固定，用户可以转头及移动观察；控制面板为独立可移动空间窗口，
使用系统玻璃背景与拖拽栏。棋盘上方仅在面板收起或关闭时显示恢复入口。
面板宽640dp，主页高480dp、棋盘设置页高368dp，使用Spatial UI原生控件。
仅在页面切换时调整窗口高度，不随回合提示改变窗口尺寸；无底部提示文案。
难度为单选分段控件，切换时先取消当前抓取；新对局用原生AlertDialog确认。
碰撞体仅用于指向与手势命中，棋子落点由规则与吸附动画控制，不采用重力自由掉落。

## 性能设计

动物每个模型合并为单mesh；16枚动物和场景资产合计135,608三角形，
比1.0.1的191,064减少29.0%；19个GLB从5,064,120字节降至3,608,080字节。
棋盘河纹由圆管改为窄带网格，棋盘三角面降至8,288。

全部GLB使用不透明单面材质；柔和明暗烘焙到线性顶点色，避免sRGB字节误作线性导致发白。
使用KHR_materials_unlit，运行时不创建环境光、实时投影或PBR方向光；地形与动物的几何轮廓仍为真实3D。
由于光照烘焙到模型本地，旋转棋桌时明暗随模型一起旋转，这是本版卡通风格的取舍。

复用格子形状、高亮网格、材质；缓存选中棋子的合法落点，仅对高亮样式变化的格子提交原生更新。
棋子位置未改变时不重复提交可访问性状态；每帧只更新动画或被抓取的棋子。
高亮材质显式持有，直到场景关闭才释放，避免失去最后一个引用后再次使用已关闭材质。
使用本地GLB，无运行时网络素材请求；AI不占用UI主线程。
终局庆祝复用固定的72个火花与72个短尾迹实体、同一网格及3种不透明Unlit材质；每帧更新位置与尺寸，
不创建动态光源、物理刚体或新实体。烟花位于Stage空间，独立于棋桌旋转和升降；场景关闭时随其资源统一释放。
实际设备采样与验证范围见`验证记录.md`。
