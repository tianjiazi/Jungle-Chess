# 1.13 历史验证 — 应用内天空沉浸度

日期：2026-11-24。包名 `com.pico.junglechess`，versionName=1.13，versionCode=16。

## 调节方式

主操作面板底部「棋盘设置」旁增加「天空沉浸度」。天空设置页采用原生Spatial UI
滑杆及三个快捷按钮：全透0%、半沉浸50%、全沉浸100%。首次默认100%，即时生效，
保存在本机SharedPreferences。关闭设置、重开棋局、关闭面板及重新进入应用保留选择。
主面板保持640×608dp，天空设置页与棋盘设置页为640×368dp；棋盘原有5个控件保留。

| 沉浸度 | 天空 | 其他内容 |
|---|---|---|
| 0% | 独立天空实体关闭，周围显示VST | 棋盘、棋子、树、地面装饰、烟花仍显示 |
| 1–99% | 天空材质透明度等于百分比，与VST混合 | 可见性、材质、摆放及交互不随滑杆变化 |
| 100% | 天空恢复不透明渲染 | 保持原有场景 |

## 实现与系统限制

使用Mixed Stage（manifest style=1），避免系统对Stage内全部3D模型施加沉浸度遮罩。
沉浸度由应用内控件调节，**系统旋钮不控制这项天空设置**。
`SkySettings`由Stage持有，与面板共享；`JungleScene`只调整`sky.glb`的独立实体、
UnlitMaterial opacity、blending和depthWrite。非天空实体不做随沉浸度变化的修改。
原有真实动物叫声和两项音频开关保留。

本轮曾临时使用Progressive Stage，在应用正常启动后分别采集100%和0%画面。
100%显示天空、森林和棋子；0%只保留操作面板及VST，棋盘和森林模型消失。
与SDK文档`en_open-or-close-stages.md`中关于Progressive影响3D模型显示的说明一致。
故最终实现改为Mixed。早期测试进程结束后的VST截图不用于此结论。
含真实办公室与人员的VST截图不放入源码或交付包。

| 背景音乐 | 棋子音效 | 行为 |
|---|---|---|
| 开 | 开 | 保持原有背景曲和棋子真实动物叫声 |
| 关 | 开 | 背景曲立即暂停，点选和抓起仍播放叫声 |
| 开 | 关 | 背景曲继续；停止正在播放的叫声，后续选择静音 |
| 关 | 关 | 暂停背景曲、停止叫声、放弃音频焦点 |

## 实现

`BackgroundMusic`作为Stage唯一音频所有者，保存两项设置的StateFlow，
分别控制MediaPlayer和SoundPool。操作面板通过同一PanelSession绑定访问
Stage音频对象，不创建另一播放器。关闭背景音乐不会禁用棋子音效；
音频焦点由场景可见性及两个开关的组合状态决定。
